## 多电脑同步

详见 [SYNC-GUIDE.md](SYNC-GUIDE.md)。基本规则：**开始编辑前 Pull，结束编辑后 Commit + Push；不同设备不要同时编辑同一文件。** 第二台电脑首次需要 Clone 仓库，并通过 GitHub 身份验证（私有仓库不能匿名克隆）。

## 修改约定

- 核心十区文件保留原文件名，方便 Obsidian 和 AI 关联。
- 新内容可以在 `knowledge/` 内按主题扩充，增删或重命名后同步更新 `manifest.json`。
- 客户案例先脱敏，不上传联系人、收件地址、验光处方照片和敏感商业数据。
- 不把 `main` 分支的历史文档当成自动实时更新的 AI 记忆；不同 AI 需配置仓库访问，并在任务时主动读取。
